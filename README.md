# 合成EsiLA

线上游玩：https://esila-game.pages.dev/ 。托管和更新说明见 `Cloudflare发布.md`。

无需安装依赖，双击 `index.html` 即可游玩。也可以在本目录运行 `node server.cjs`，访问 http://127.0.0.1:5173。

- 电脑：移动鼠标，点击放下；或使用左右方向键移动、空格 / 回车放下。
- 手机：触摸游戏区域选择位置并放下水果。
- 相同水果碰撞会合成下一等级。超过顶部虚线持续一段时间，游戏结束。
- 槽的逻辑高度为 710，虚线到底部的堆叠空间较初版增加约 25%。
- 按 1 → 2 → … → 11 的顺序合成，合出11号 EsiLA 即可达成目标，也可以继续合成。
- 合成 2—10 号依次加 1、2、3、4、5、6、7、8、9 分。合出11号后，本局总分固定为 388 分。
- 最高分保存在当前浏览器。右上角可开启音效，左侧可重新开始。

11 个等级依次使用 `新建文件夹` 内的编号图片：1—8 和 11 为 `.jpg`，9、10 为 `.png`。1 号最小，11 号最大。游戏、下一颗预览和图鉴使用同一套图片，保留弹性碰撞和合成效果。所有资源都在本地，无外部字体或图片请求。

`physics.js`：固定时间步长圆形刚体、碰撞与合成。`game.js`：绘制、交互与游戏流程。`style.css`：电脑与手机布局。

验证物理逻辑：`node --test physics.test.cjs`。
